# Bloom Universe 🌸✨

Official Community Portal for **Bloom Universe** — a modern, cozy, arcade-styled community platform featuring Discord role integrations, interactive 3D elements, Cloudinary/Uploadthing media uploads, PostgreSQL database, and bilingual support (EN/ID).

## 🚀 Tech Stack

- **Framework**: Next.js 16 (App Router + Turbopack)
- **Language**: TypeScript & React 19
- **Styling**: Tailwind CSS v4 + Cartoon 3D Design Tokens
- **Database**: PostgreSQL (Neon Serverless) + Prisma ORM
- **Authentication**: Next-Auth v5 (Discord OAuth2 Provider + Role Syncing)
- **Storage**: Uploadthing Cloud Storage
- **Timezone**: Asia/Jakarta (WIB - UTC+7)

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Run database migrations
npm run prisma:push

# Seed initial data
npm run db:seed

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
